Cloud Computing

Cloud Computing

Provisión bajo demanda de recursos informáticos a través de internet, como servidores, almacenamiento y aplicaciones, que pueden ajustarse según las necesidades.

SaaS

Software como servicio. El usuario accede a una aplicación por internet y el proveedor se encarga de operarla, mantenerla y actualizarla.

PaaS

Plataforma como servicio. Ofrece un entorno administrado para desarrollar, probar y desplegar aplicaciones sin gestionar la infraestructura subyacente.

IaaS

Infraestructura como servicio. Proporciona recursos virtualizados de cómputo, almacenamiento y red. El usuario administra los sistemas operativos y las aplicaciones.

Virtualización

Tecnología que abstrae los recursos físicos para crear entornos virtuales independientes, como varias máquinas virtuales que comparten un servidor físico.

Docker

Plataforma para empaquetar aplicaciones y sus dependencias en imágenes, distribuirlas y ejecutarlas en contenedores aislados que comparten el núcleo del sistema anfitrión.
